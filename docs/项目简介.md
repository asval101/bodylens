# 项目简介（报名表单用）

> 三个长度，按表单字数上限取用。数字都能在仓库里核对：
> 30 条行为 / 7 个分类见 `data/catalog.js`，85 项测试跑 `npm test`，
> 4986 行 = JS 3460 + CSS 1299 + HTML 127（不含 `docs/`、`tests/`、`scripts/`）。

## 300 字版（主用）

身知 BodyLens 把日常行为折算成「少活了多久」，让用户看见今天的每件小事落在身体哪里。

医学研究给出的结论多是「风险上升百分之几十」，普通人很难把它和自己的明天对上。身知换了个单位：一支烟约 20 分钟，两小时久坐也有一笔账。点一下今天做过的事，就能看到这个数字、它出自哪份研究、区间有多大，以及它落在肺、心还是脑。

三条硬规则贯穿全站：有数字就必须有出处和误差区间；大模型只负责把结论换成人话，一个数都不许碰；不替用户做决定，也不把「早睡」折算成抵扣烟的钱——收益和损耗不抵消。

技术上刻意选了原生 HTML/CSS/JS：零运行时依赖、断网可用、无账号无数据库，约 5000 行代码配 85 项自动化测试。

在线演示：https://body-ledger.com

## 100 字版（短栏位）

身知 BodyLens 把抽烟、喝酒、熬夜、久坐折算成「少活了多久」——一支烟约 20 分钟。每个数字都带研究出处和误差区间，大模型只换措辞、不碰数字。原生零依赖，断网可用，无账号无数据库。在线体验：body-ledger.com
