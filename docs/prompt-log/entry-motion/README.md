# 入场动效：从「所有东西一起出现」到「分批落位」

- 日期：2026-10-20 ｜ 对应提交：`7be570f`
- 验证：桌面 1000px 与 390px 容器双尺寸截图；390px 下 `overflow count=0`
- 截图：`.tmpshot/anim-250ms.png`（动画进行中）、`.tmpshot/anim-final.png`（终态）

## 1. 初始意图（我的原话）

> 就是想让 ui 界面更高级，出场动画就是像所有按键从下到上从浅到深的那种，按你的直觉来，我认为那个人体的有点丑，不过也可以先做出来第一版，再接着改

## 2. 第一件事：先纠正一个误解

我以为「更高级」要换配色或换字体，但看代码后发现现有配色是成体系的（深青底 + 薄荷 + 铜色），字体也是系统栈。真正拉开差距的是两件事：

- **时序**：所有元素同一帧出现，页面像「刷」地一下贴上来，没有层次
- **节奏**：`gap` 全站统一 36px，段落之间没有主次差别

所以这一轮不碰配色和字体，只做时序与节奏。这个判断写在这里，是因为它决定了后面所有的改动范围。

## 3. 三个实现决定

**① 只动 `transform` 和 `opacity`**

入场用 `translate3d(0,16px,0)` + `opacity` 从 0 到 1。不用 `height`、`margin`、`filter`。理由是布局属性每帧都要重算，而这个页面本身已经有人体 SVG 和粒子层，不能再加重绘负担。

**② 分层延迟，不是统一延迟**

| 元素 | 延迟 | 时长 |
|---|---|---|
| 主区块（6 个） | 40 / 130 / 210 / 270 / 320 / 360ms | 620ms |
| 主数字 | 120ms | 820ms |
| 行为 chips | 180ms + i×34ms | 520ms |
| 数量按钮 | 60ms + i×40ms | 460ms |

主数字单独走一条更慢的曲线，晚到 120ms、位移幅度更大（22px）。效果是视线先看到它，再看到周围的辅助信息。这是整屏唯一允许「抢跑」的元素。

**③ 选中态换了一种做法**

原来是整体变色（边框、背景、文字全变）。改成**底线从中间向两侧展开**：

```css
.entry-chip::after{
  left:50%; right:50%;
  transition:left 300ms, right 300ms;
}
.entry-chip.is-picked::after{left:13px; right:13px}
```

理由是变色只说明「状态变了」，而展开的线说明「这一项被展开了」，它同时暗示了下面会出现数量选项。**线比色更能表达因果。**

## 4. 差点踩进去的坑：截图说移动端溢出，实际没有

390px 截图里右侧明显被裁——导航「今日计划」断了、chips 被切、记录行的分钟数看不见。

第一反应是加 `overflow-x:hidden`，但那是掩盖问题而不是修问题。于是建了一个 390px 的 iframe 包裹页实测：

```
viewport=390
doc.scrollWidth=390  body.scrollWidth=390
overflow count=0
```

**零溢出。** 再用 390px 固定容器截图，布局完整：8 个 chips 正常换成三行，记录行数值全在。

结论：Edge headless 在 `--window-size=390` 时并不按 390 排版，截图窗口和实际视口是两回事。**这是测量工具的假象，不是代码缺陷。** 如果当时照着截图去改，会往一个不存在的 bug 上打补丁。

## 5. 无障碍降级

系统开启「减少动态效果」时，不能只是把动画变快，那样仍然是「一个个冒出来」。改成一次性纯淡入、延迟归零：

```css
@media(prefers-reduced-motion:reduce){
  .today > *, .hero-number, .entry-chip, .qty-btn{
    animation:fade-only 180ms linear both !important;
    animation-delay:0ms !important;
  }
}
```

## 6. 顺带记下但没动的两件事

- **人体图偏「半写实」**：既有解剖细节又有肉色渐变，落在既不像图谱也不像示意图的中间地带，在深色底上显得浑浊。用户已同意先留着，下一轮处理。
- **配色有「AI 味」**：深青底 + 薄荷绿是很典型的生成式配色。但这套颜色已经贯穿全站（探索页、器官高亮、免责说明都在用），单独改首屏会割裂，需要整站一起评估。

## 7. 一句话复盘

这轮真正省时间的不是写动画，是**没有相信截图**。工具说溢出的时候，先问「工具测的是不是我以为的那个东西」——省下的是一次错误的修补和它带来的副作用。
