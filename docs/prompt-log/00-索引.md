## 记录要求

每份记录必须包含：

1. **用户原始 Prompt**（原文粘贴，不改写、不润色）
2. **AI 首轮输出与具体问题**（哪里不对，不是「不太满意」）
3. **人工纠偏的 Prompt 与取舍**
4. **最终结果**（测试、截图、提交号）
5. **一句话复盘**

只写结论不写过程的记录不算数——评审标准看的是判断过程，不是结果清单。
