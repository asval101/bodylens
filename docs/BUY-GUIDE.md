# 买服务器和域名 · 手把手版

> 价格是 2026-10 查到的公开标价，活动价会浮动，**以结算页显示为准**。  
> 全程约 60 分钟，其中 20 分钟在等审核，不用一直盯着。



---

## 零、先看这张图：顺序不能乱

```
① 注册腾讯云账号 → ② 实名认证 → ③ 买服务器（香港）
                                      ↓
                              ④ 买域名 → ⑤ 域名实名（等审核）
                                      ↓
                              ⑥ 域名解析到 IP → ⑦ 服务器放行 80/443
                                      ↓
                                   ⑧ 装证书，出 https
```

**为什么不能先买域名：** 没实名的账号，域名买不了。没服务器的 IP，解析没地方指。

## 一、注册账号 + 实名（10 分钟，必须第一步）

1. 打开 `cloud.tencent.com`
2. 右上角「注册」→ 微信扫码，30 秒
3. 扫码后进去，顶部会有一条黄色提示「您还未实名认证」→ 点它
4. 选 **个人认证**
5. 填：真实姓名 + 身份证号 → 用微信扫脸（或者上传身份证正反面）
6. 等 1–3 分钟，通过

**这一步不做，后面什么都买不了。** 服务器要实名，域名要实名，是两次不同的实名。

顺手做：右上角「费用」→「支付方式」→ 绑微信或支付宝。不绑的话最后一步付不了款。

## 二、买服务器（10 分钟）

路径：腾讯云首页 → 搜索框搜「轻量应用服务器」→ 进产品页 → **立即购买**

页面上有 6 个要选的东西，一个个说：

| 选项       | 你要选的                                  | 选错的后果                           |
| -------- | ------------------------------------- | ------------------------------- |
| **地域**   | **中国香港**                              | 选成广州/上海 → 必须 ICP 备案，15–25 天，来不及 |
| **套餐**   | **2核 2G 里最便宜的那档**（香港档位规格随活动变，别背数字） | 选 1核1G 跑 Node 会卡，要开 swap       |
| **镜像**   | 系统镜像 → Ubuntu → **22.04 LTS 64bit**   | 选 CentOS 后面命令全对不上               |
| **时长**   | **3 个月**                              | 买 1 年浪费，比赛 11 月 18 号就结束了        |
| **数量**   | 1                                     | —                               |
| **自动续费** | **不勾**                                | 勾了忘关，明年自动扣钱                     |

价格：香港档位约 **40–70 元/月**（活动价可能低到 24–30），3 个月 120–210 元。看到更低就直接买。

> 页面默认会推「4核4G 特惠」之类的，别被带走。这个项目是纯静态文件 + 一个几十行的转发脚本，2核2G 属于严重过剩。

### ⚠️ 买之前必须确认：套餐的地域列表里有「香港」吗

「热门规格」页每档套餐标题下面都会列一行地域，例如：

> 入门型套餐 ｜ 新加坡/东京/硅谷/法兰克福/首尔/雅加达

**这行里没有「香港」，就说明这档买不到香港。** 这是最容易买错的地方——直接点「立即购买」，最后落地成新加坡节点，大陆访问慢一倍。

正确做法：先在页面上方的「地域」筛选框勾选 **中国香港**，让套餐列表刷新成香港专属档位，再选 2核2G。

**别为了便宜改买新加坡。** 大陆访问延迟新加坡 60–100ms 且常绕路，香港 30–60ms。评委在浏览器里等的那一两秒，就是这个差别。

**如果勾了香港后列表为空、售罄，或只剩 100 元以上的档**：不要在腾讯云耗时间，直接去阿里云买香港轻量 2核2G（约 56 元/月，香港是明确选项）。两家跑这个项目效果一样。

### 付完款，立刻做这 4 件事

**1. 记下公网 IP**  
控制台 → 左侧「轻量应用服务器」→ 点进刚买的实例，卡片上有个 `43.xx.xx.xx` 之类的地址。  
**这个 IP 抄到记事本，等下域名要指向它。** 顺便确认地域那行写的是「中国香港」。

**2. 设密码**  
实例详情页 → 「重置密码」→ 设一个 12 位以上、大小写+数字+符号的密码。  
（Linux 服务器默认没有密码，只有密钥，必须自己设一个才方便登录。）

**3. 放行端口（最容易漏的一步）**  
实例详情页 → 「防火墙」标签 → 「添加规则」，加两条：

| 应用类型 | 协议  | 端口  | 来源        |
| ---- | --- | --- | --------- |
| 自定义  | TCP | 80  | 0.0.0.0/0 |
| 自定义  | TCP | 443 | 0.0.0.0/0 |

22 端口（远程登录）一般默认已开，没有就一起加上，来源填 `0.0.0.0/0`。

**不开 80，等下域名能解析但网页打不开，会白白怀疑半小时。**

**4. 试一下能不能进去**  
实例详情页右上角有「登录」按钮，点它 → 弹出黑色终端窗口 → 输入 `root` 和你刚设的密码 → 看到 `root@VM-xx:~#` 就成功了。

或者在自己电脑上开 PowerShell，敲：

```powershell
ssh root@你的IP
```

第一次连会问 `yes/no`，输 `yes` 回车。

进去后敲一句确认环境：

```bash
lsb_release -a     # 应该显示 Ubuntu 22.04
```

## 三、买域名（15 分钟 + 等审核）

路径：腾讯云 → 顶部「域名注册」→ 搜索框输入你想要的名字 → 查询

### 起名

推荐这几个方向，先去搜一下有没有被占：

- `bodyledger.com`（最贴作品名）
- `body-ledger.com`
- `bodylens.com`（"身体透镜"，镜头感更好）
- 被占了就在后面加 `app` / `hq` / 年份，例：`bodyledger-app.com`

### 选后缀

**只选 `.com`。** 首年 83 元，续费 90 元/年。

| 后缀                 | 首年      | 续费       | 结论                   |
| ------------------ | ------- | -------- | -------------------- |
| .com               | 83 元    | 90 元     | ✅ 买这个                |
| .cn                | 33 元    | 38 元     | ❌ 内容涉及健康器官，被举报可直接停解析 |
| .top / .xyz / .icu | 10–15 元 | 80–450 元 | ❌ 首年便宜是钓饵，续费翻十倍      |

省 50 块换一个随时可能消失的链接，不划算。

### 付款时会卡住的地方：信息模板实名

第一次买域名，结算页会让你「创建信息模板」，这是注册局强制的：

1. 模板类型选 **个人**
2. 填：域名持有者姓名（和身份证一致）、身份证号、手机号、邮箱、通讯地址
3. 上传身份证正面照片（手机拍，四角拍全，别反光）
4. 提交 → 等注册局审核

**审核一般 1–2 小时，最长 1 个工作日。** 审核通过前，域名状态是 `serverHold`（暂停解析）——这时候你去加解析记录，加了也不生效，不是你的操作错了。

买完在「我的域名」里能看到：域名、到期时间、状态。**状态变成「正常」才能用。**

## 四、把域名指向服务器（5 分钟）

路径：腾讯云 → 「DNS 解析 DNSPod」→ 点你的域名 → 「添加记录」

加两条，内容一模一样，只有主机记录不同：

| 主机记录  | 类型 | 线路 | 记录值     | TTL |
| ----- | -- | -- | ------- | --- |
| `@`   | A  | 默认 | 你的公网 IP | 600 |
| `www` | A  | 默认 | 你的公网 IP | 600 |

- `@` 代表 `bodyledger.com`
- `www` 代表 `www.bodyledger.com`
- 两条都指同一个 IP，别人加不加 www 都能打开

保存后等 10 分钟。验证：自己电脑 PowerShell 里敲

```powershell
nslookup bodyledger.com
```

下面出现 `Addresses: 43.xx.xx.xx`（你的 IP）就通了。

| 症状                | 真实原因                 | 怎么办                 |
| ----------------- | -------------------- | ------------------- |
| 购买页找不到「中国香港」      | 默认帮你选了广州             | 地域那一栏点开，手动往下翻找香港    |

| 首年 83 元，第二年变 90 元 | 域名是按年租，不是买断          | 正常，记得每年续            |
| 香港服务器打开有点慢        | 香港轻量没有大陆直连线路         | 见下面「速度」那段           |

### 关于速度，说实话

香港轻量走的是国际 BGP，大陆访问首屏大概 1–2 秒。对比赛演示够用——项目里所有页面都是本地渲染，不依赖外部 CDN，网络慢只是慢一点，不会白屏。

想更快只有两条路：买带 CN2 直连的云服务器（价格是轻量的 5 倍以上），或者回大陆备案（来不及）。**都不值，别折腾。**

想换阿里云也行：香港轻量 2核2G 约 56 元/月，带宽标 200M，但流量只算上行、超额另计费。两家都能跑这个项目，就近选一家，别同时买。

## 七、一共花多少钱

| 项目                      | 金额          |
| ----------------------- | ----------- |
| 轻量服务器 2核2G（香港）× 3 个月    | 120–210 元（看档位与活动，以结算页为准）     |
| 域名 .com 首年              | 83 元        |

**页面会推荐你一起买的东西，全部不要：**

- SSL 证书（几千块那个）—— Let's Encrypt 免费，同样的小锁图标
- 云数据库、对象存储、CDN —— 这个项目不存数据库，没有图片要加速
- 企业邮箱、网站模板、域名隐私保护（可选，20 元/年，不买也能用）
- 备份服务 —— 代码在 git 里，服务器挂了重装半小时

## 八、买完把三样东西发我

1. **公网 IP**（`43.xx.xx.xx`）
2. **域名**（`bodyledger.com`）
3. **域名状态**是不是「正常」

有这三样，我直接开始部署：传代码、装 Node、起服务、签证书，你只需要在终端里粘贴命令。

## 附：为什么必须是「香港 + .com」

| 组合               | 结果                                             |
| ---------------- | ---------------------------------------------- |
| 大陆服务器 + 任何域名     | 必须 ICP 备案，个人备案禁止医疗健康类内容，周期 15–25 天 → 赶不上 11/18 |
| 香港服务器 + .cn      | 不用备案，但 .cn 是境内注册局管理，健康类内容被举报可停止解析              |
| **香港服务器 + .com** | **不用备案，当天可用，注册局在境外，链接稳定** ✅                    |
