# UI 实现规格（UI-SPEC）

PRD 第 5.4 节定义视觉方向，本文件提供**可直接落地的数值**。两者冲突时以 PRD 为准，并回来修正本文件。
所有数值取自现有 `styles.css` 的 `:root`，新增样式必须复用变量，不得硬编码新色值。

---

## 1. 色彩 token

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#080f11` | 页面底色（近黑带青） |
| `--panel` | `#101a1d` | 面板、卡片 |
| `--panel-deep` | `#0c1518` | 下沉区域、代码块 |
| `--text` | `#edf2ed` | 主文字（微暖白，非纯白） |
| `--muted` | `#9baead` | 次级文字 |
| `--faint` | `#697f80` | 辅助、说明、页脚 |
| `--line` | `#263538` | 边框、分隔线 |
| `--mint` | `#9cdec9` | **交互强调色**：焦点环、选中态、可点击 |
| `--mint-ink` | `#0c2925` | 薄荷底上的文字 |
| `--copper` | `#e6a48c` | **不利影响**语义色 |
| `--positive` | `#9cdec9` | **有益作用**语义色 |
| `--radius` | `#18px` | 面板圆角 |

其它既有硬编码值（复用时保持一致）：输入框底色 `#111e21`、输入框边框 `#2b3d40`、占位符 `#708687`、选中文本 `#395e58`。

### 语义色规则
- **不利影响**（`harm`）：铜色 `--copper`，用描边或标记呈现，不得把器官本体染成铜色。
- **有益作用**（`benefit`）：薄荷 `--positive`。
- **多重 / 条件相关**（`mixed`）：**目前数据中不存在该类型**，需先补数据与规则，再补一个双色标记样式（铜+薄荷渐变描边），不得复用单一色。
- **当前未收录**：用 `--faint` 中性灰 + 文字说明，**不得使用绿色或任何“安全”暗示**。
- 器官本体保留自然色泽。禁止把全部器官统一荧光化。

## 2. 字体与排版

`"Segoe UI", "Microsoft YaHei", "PingFang SC", sans-serif`，基准 `14px / 1.65`。
品牌字 `24px`，字距 `3px`。器官英文字号为 `10–11px` 大写+字距，仅作装饰信息，不承载关键内容。

字号阶梯（既有实现，新增文字就近取档）：
`46px`（指标数字）· `33px`（h1，窄屏 27px）· `19–24px`（区块标题）· `17px`（面板标题）· `14px`（正文）· `12px`（说明）· `11px`（注释）· `10px`（器官标签）· `8–9px`（图例）

## 3. 布局

- 容器最大宽度 `1640px`，左右 `42px`；≤1180px 时 `25px`；≤650px 时 `18px`。
- 顶栏高度 `88px`，底部 `1px solid var(--line)`。
- 工作区三列：`290px / minmax(400px,1fr) / 370px`，间距 `28px`（≥1500px）；
  ≤1180px 收窄为 `240px / 1fr / 290px`；≤980px 变为两列，详情区降到整行；≤650px 单列堆叠。
- 人体场景固定高度：桌面 `605px`、≤1180px `540px`、≤980px `590px`；沉浸模式 `635px`。
- 详情面板 `max-height: 790px` 内部滚动（沉浸模式 870px）。

## 4. 氛围与景深（对应 PRD“背景景深”要求）

- 环境光：两团径向模糊光斑，`#174941`（760×660，blur 150px，opacity .19）与 `#47322a`（500×500，opacity .13），通过 `--ambient-x/y` 做轻微视差。
- 地平线辉光：`radial-gradient(ellipse at 50% -20%, #1d393333, transparent 60%)`。
- 光斑位移必须跟随鼠标/滚动做**极小幅度**偏移（建议 ≤12px），不得做成跟随光斑。
- 景深只允许通过模糊、亮度、层叠顺序营造，不得使用大面积 `filter: blur()` 让文字区域失焦。

## 5. 动效

| 项 | 约束 |
| --- | --- |
| 允许属性 | `transform`、`opacity` |
| 悬停反馈 | 轻微上浮/放大，**不得挤动相邻器官**，命中区不得错位 |
| 时长 | 交互反馈 150–250ms；场景切换 ≤450ms |
| 缓动 | `cubic-bezier(.2,.7,.3,1)` 或 `ease-out` |
| 禁止 | 持续闪烁、常驻粒子雨、呼吸式发光压过文字、伪造扫描进度条 |
| 减少动态 | `prefers-reduced-motion: reduce` 下全部关闭（`styles.css` 已有全局规则，新增动画必须被该规则覆盖） |

**诚实性红线**：任何光效、扫描线、加载动画都不得表现为“正在检测用户身体”。不得出现进度百分比暗示检测。

## 6. 组件状态（缺一即视为未完成）

| 组件 | 必须覆盖 |
| --- | --- |
| 行为 chip | 默认 / hover / 选中 / 已在选择中（禁用重复） |
| 器官 | 默认 / hover 摘要 / 点击锁定 / 有不利影响 / 有有益作用 / 无资料 |
| 主按钮 | 默认 / hover / active / disabled / 处理中 |
| 输入框 | 默认 / focus（边框转 `--mint`）/ 校验失败（附字段级原因）/ disabled |
| 详情面板 | 有结论 / 未收录 / 资料加载失败可重试 |
| 今日计划 | 空态 / 有任务 / 已完成 / 原关联资料不可用 |
| 备份恢复 | 校验中 / 摘要确认 / 成功 / 拒绝（原因 + 原数据完整）/ 可撤销 |

## 7. 反模式清单

- 把器官画成均匀发光的图标，失去结构识别
- 用颜色单独表达影响类型而不给文字图例
- 深色界面上用纯白 `#fff` 正文（眩光，且与本项目暖白基调冲突）
- 输入区、人体、详情三栏在 1024px 下互相挤压出横向滚动
- 悬停高亮把相邻器官推开导致点击错位
- 空态写成“暂无数据”而不解释原因与下一步
