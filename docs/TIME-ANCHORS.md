# 时间类比换算表

## 用途

把「多少分钟」翻译成用户真实经历过的事情。

**分钟是计算单位，类比是表达单位。** 两者都要有，缺一个都不成立：只有分钟没有类比，用户会「小化」它；只有类比没有分钟，无法累加、无法对比、无法追溯。

## 三条铁律

1. **类比只做翻译，不做计算。** 底层分钟数必须能追到出处，类比是它的显示层，不能反过来用类比去估算。
2. **只在 0.5×–2× 区间使用。** 160 分钟写「将近一部电影」，不写「1.78 部电影」。超出区间就换下一个量级的参照物。
3. **一屏最多两处类比。** 第三处开始就变成修辞噪音，用户会觉得在煽情。

## 换算表

目标用户：18–30 岁，大学生或刚工作。

| 量级 | 参照物 | 建议写法 |
| --- | --- | --- |
| 约 10 分钟 | 泡一碗面、刷二十条短视频 | 十几分钟 |
| 约 20 分钟 | 从宿舍走到教学楼、一集短剧 | 不到半小时 |
| 约 45 分钟 | 一集电视剧 | 将近一集剧 |
| 约 90 分钟 | 一部电影 | 一部电影 |
| 约 3 小时 | 一部电影加一集剧 | 大半个下午 |
| 约 7 小时 | 一整晚睡眠 | 一整晚的睡眠 |
| 约 24 小时 | 一整天 | 整整一天 |
| 约 1 周 | 一门课一周的复习量 | 将近一周 |
| 约 1 个月 | 一个学期的一小段 | 一个多月 |
| 约 1 年 | 一整个学年 | 一整年 |

## 写的时候

- 用「大约」「将近」「差不多」，不要给类比加精确修饰。
- 收益和损耗共用同一套参照物。只给损耗找参照、收益干巴巴写数字，用户会觉得在糊弄。
- **不用**「少活 X 年」「生命倒计时」这类写法。它把类比变成了恐吓，和产品「可挽回」的立场冲突。
- 拿不准量级时，宁可只给分钟数，不加类比。写错的类比比没有类比更伤。
