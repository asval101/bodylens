# 显示方式：牵连与留存

> 验证原型：`design-lab/echo.html`（独立单文件，零依赖，不读写 localStorage）
> 状态：方向验证，未接入 `app.js`

## 1. 要解决的问题

用户反馈现有界面「不够直观」，希望让用户真正意识到行为对身体的后果，并在做有害行为时产生阻力。

常见解法是把后果换算成数字：风险倍数、健康评分、寿命分钟。这条路有三个绕不过去的坎：

- **数字会诱导Linear外推。** 每天 1 支烟的风险已达每天 20 支的约 46%，按支数线性折算只会算出 5%，差 9 倍。
- **数字必须落到"人群平均"上。** 一旦用户拿「我认识的人抽了一辈子也没事」来反驳，整个产品的可信度就没了。
- **数字暗示可加减。** 「少活 20 分钟」天然让人以为可以靠运动赚回来，而 WHO 的证据并不支持这种抵消。

而项目已有的 `data/catalog.js` 本身就写明了「现有资料不支持按每坐一小时计算损伤」。也就是说，数据层面早已拒绝了量化表达，只是界面还没跟上。

## 2. 核心命题

**不给分数，给留痕。**

不问「这件事有多坏」，只回答两个问题：

1. **牵动了哪几处**（空间）
2. **会留多久**（时间）

这个转换带来三个结果：

- 不需要个体概率，因此不触碰 PRD 的内容红线
- 不需要线性外推，因此不会被剂量曲线证伪
- 天然区分「现在停还来得及」和「停不下来」，因此指向行动

## 3. 三个维度

| 维度 | 编码方式 | 读法 |
|---|---|---|
| 方向 | 颜色：暖红 = 不利，暖绿 = 有益，琥珀 = 同一处被拉向两边 | 这是好事还是坏事 |
| 强度 | 轮廓亮度与填充浓度 | 影响有多大 |
| 留存 | 外围虚线环的粗细 | 停手之后多久才散 |

「被拉向两边」这一档对应 PRD 5.5 要求的第四种影响状态（多重/条件相关），当前 `catalog.js` 尚缺 `mixed` 类型，原型已在视觉层预留。

## 4. 六档回落刻度

所有影响都用同一把尺子衡量——**停手之后多久消失**：

```
数小时 · 数天 · 数周 · 数月 · 数年 · 不完全回落
```

这把尺子的价值在于统一。它让"喝水"和"抽烟"可以放在同一张桌子上比较：

- 喝水：肾脏受益**数小时**，所以每天都要喝，攒不成资本
- 刷牙：口腔受益**数小时**，所以才需要一天两次
- 抽烟：肺**数月**、心**数年**、肾**不完全回落**

用户不需要理解流行病学，就能自己得出结论。这比任何说教都有效。

**「有益行为也会回落」是这个框架里最重要的诚实。** 它阻止用户把健康行为当成存款，也顺带解释了为什么习惯需要每天重复。

## 5. 两种视角

顶部切换「此刻 / 如果一直这样」：

- **此刻**：所有影响都显示，包括那些几小时就散去的
- **如果一直这样**：短期影响整体退场，只留下会沉淀的部分

切换时画面会真的变——眼睛、脊柱、肠道暗下去，肺、心、口腔、肾留着。这个"褪去"的动作本身就是论证：**你现在担心的那些，大部分会自己消失；留下来的那几个，才是需要处理的。**

前后两个视角的数字也会同步变化（8 处 → 5 处），让"哪些是暂时的"变成可以数出来的事实。

## 6. 视觉语言

- 人体是**线稿**，不追求解剖精度：结构可辨即可，明确不冒充医学插画
- **颜色只出现在被影响的地方**：未受影响的身体近乎无色，画面里的每一处暖色都是信息
- 受影响器官带缓慢呼吸（6.4s，各器官错相），表达"这是活的、正在变化的"
- 标签仅在器官被点亮时出现，未选择时画面保持干净的人体
- 两侧竖排铭文补足图谱气质，不承载信息

## 7. 文案原则

右栏每一条影响由三句话组成，全是日常语言：

1. **此刻**：现象，不说机制名词（「烟刚到肺泡，纤毛被麻痹，暂时扫不动灰尘」）
2. **长期**：后果，附证据强度提示（「长期暴露与肺癌、慢阻肺相关，是证据最扎实的一项」）
3. **回落**：停手后的实际走向，包括不可逆的部分（「牙龈炎症数月内改善，已吸收的牙槽骨不会回来」）

第 3 句是整套设计的关键。多数健康应用只讲危害，不讲撤销条件；而人真正需要的是撤销条件。

## 8. 实现约束

- 单文件、零依赖、离线可用，符合 AC-24
- 不引用 `app.js` / `domain.js` / `vfx.js`，不写 localStorage
- 动效遵循 `prefers-reduced-motion`
- 同一器官的多个行为取最大值而非相加——相加就是被我们批评的线性外推
- 强度低于 0.05 的器官不点亮，因为"几乎没有影响"本身需要被看见

## 9. 接入真实数据前要补的字段

原型用的是 12 条行为的示意数据。接到 `catalog.js` 时需要为每个 `effect` 补三项：

```js
{
  organ, type,
  near, far,        // 此刻 / 长期 的强度 0-1，由文案强度人工标定
  back: 'hours' | 'days' | 'weeks' | 'months' | 'years' | 'never',
  layer: 'A' | 'B' | 'C' | 'D'   // 证据等级，对应 UI-SPEC 的分级
}
```

`back` 是新增的核心字段，必须逐条人工判定，不可由代码推导。`layer` 用于后续在界面上标注证据强弱。

## 11. 推进镜头（echo-zoom.html）

点击器官，镜头推进到该器官内部。参照的不是"图片放大"，而是 MIUI 超级壁纸的做法：**一条连续的轴，从远景推进到近景，全程不切断**。

### 11.1 三条必须成立的规则

小米那套效果之所以成立，靠的不是缩放动画，而是下面三点。少任何一条，就会退回成"给元素加 scale"。

1. **所有层同轴移动，但速度不同。** 近层长得快，远层长得慢，因此在同一焦距上对齐、在边缘错开。这是深度感的来源。
2. **细节只在靠近后存在。** 远处看到的是一颗平滑的球，推近了才看见环形山。器官同理：1× 时只有轮廓，3× 之后微观结构才浮现。
3. **过渡不被打断。** 推进途中有新指令，是改目标而不是重启动画。

### 11.2 实现：五个层 + 一个焦距

每个层单独计算：

```js
s  = 1 + (z - 1) * depth        // depth 各不相同
tx = 200 - fx * s               // 焦距点始终映射到画布中心
ty = 380 - fy * s
```

| 层 | depth | 作用 |
|---|---|---|
| 尘埃与同心环 `farLayer` | 0.40 | 提供参照物，否则纯色背景没有速度感 |
| 人体骨架 `bodyLayer` | 0.88 | 推进时退成背景，同时保留"你在身体里"的空间线索 |
| 连接线 `linkLayer` | 0.95 | 早退场，避免被放大成噪声 |
| 器官 `organLayer` | 1.00 | 主体 |
| 微观结构 `microLayer` | 1.00 | 必须与器官同深度，否则 4× 时会错位到轮廓外 |

> 微观层深度必须等于 1。差 0.07 时，距焦点 30 单位的细节会偏移 10 单位，肉眼可见"内壁浮出器官外"。

### 11.3 缓动：欠阻尼弹簧，不是贝塞尔曲线

```js
VEL += (TGT - CAM) * 108 * dt;
VEL -= VEL * 16.5 * dt;
CAM += VEL * dt;
```

阻尼比约 0.76，会略微冲过目标再回稳。这是物理感的来源——任何 `cubic-bezier` 都做不出"冲过去一点"的手感。改目标时只改 `TGT`，速度连续，动画因此天然不被打断。

### 11.4 距离相关的状态

| 量 | 规则 | 目的 |
|---|---|---|
| 身体不透明度 | `max(0.05, 1 - (z-1)*0.33)` | 推到 4× 时人体几乎消失 |
| 微观层 opacity | `(z - 1.9) / 2.2` | 1.9× 开始出现，4.1× 到满 |
| 运动模糊 | `|Δz| × 0.22`，上限 2.6px | 只在移动时存在，停下即消失（取代景深） |
| 标签与外环 | `z > 2.05` 时关闭 | 放大后的标签是噪声 |
| 非聚焦器官 | `z > 2.05` 时降到 0.13 | 只留一个主体 |

### 11.5 缩放倍数要按器官尺寸标定

固定倍数会让小器官"悬在画面中央"。倍数由 `z` 字段逐器官给定：口腔 10.5、眼睛 7.2、胃 8.0、心脏 6.8、大脑 5.2、肺 4.7、脊柱 2.9。约束是画布宽 400 单位——器官宽度 × z 不能超过 400，否则被裁切。

### 11.6 微观结构：一套生成器，不是图片

十个器官各有一套程序化生成，只在推进时渲染：

| 器官 | 结构 |
|---|---|
| 肺 | 递归二分叉的支气管树 |
| 心 | 冠状动脉分支 + 心肌同心弧 |
| 脑 | 横向脑回褶皱 + 纵向脑沟 |
| 肝 | 六边形小叶网格 |
| 肾 | 开口朝内的皮质弧 + 肾门放射管 |
| 胃 | 横向黏膜皱襞 |
| 肠 | 沿壁排列的绒毛 + 三道结肠袋 |
| 口腔 | 上下两排牙冠 + 牙龈线 |
| 脊柱 | 椎体序列 + 椎间盘 |
| 眼 | 虹膜环 + 放射状纹理 |

线条一律 `vector-effect: non-scaling-stroke`，放大后仍是发丝粗细，读作精密而非糊成色块。

### 11.7 踩过的三个坑

- **y 轴方向**：SVG 的 y 向下。用 `-π/2` 画"向下生长"的支气管树，会整棵树长到肺外、被裁剪掉，表现为"微观层完全没出现"。
- **逐帧写 opacity 又挂 CSS 过渡**：过渡每帧被重启，永远停在起始值。`inline` 是 0.05 而 `computed` 是 1，肉眼表现为"人体根本没退场"。逐帧动画的属性不要再挂 transition。
- **`vector-effect` 与描边宽度**：器官轮廓放大 5× 后描边会变成 5 倍粗，必须加 `non-scaling-stroke`，否则放得越大越像卡通。

### 11.8 降级

- `prefers-reduced-motion`：直接落位，不做推进。
- 触屏与窄屏：关闭鼠标视差，其余保留。
- 断网：无任何外部依赖，全部结构在本地生成。
