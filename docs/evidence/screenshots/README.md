## 关于「线上」这两个字

抓这八张图的时候，本机杀毒软件把 `body-ledger.com` 的浏览器访问拦了（报「加密诈骗网站」，属误报）。
所以取图方式改成：用 SSH 从服务器 `tar` 出 `/opt/bodyledger` 的真实文件，在本地起静态服务再拍。

因此这几张图拍的是**服务器上那份文件**，不是本地仓库的副本。取图前做过校验和比对：

```
67cf1a6ed32def623d8fdd1312e97dd2  app.js      （本地与服务器一致）
fb64afc33ee25d4c3eba354f37cc2627  index.html
b4b5cb093351403fe4f9a8550e02a981  styles.css
2f9adb179ca06ef181539d76efe0556f  today.css
c0bcc8bc4c7a4ba6d406dc7ddae1c1ad  today.js
```

五个文件两端一致，所以图里的界面就是线上界面。
