# 身知 BodyLens

把日常行为的后果映射到人体，帮助用户理解影响、查看证据并决定今天的一个小行动。

当前版本 **V0.1** 是本地可运行的 Web 应用。没有账号、付费接口、数据库、在线模型或前端构建依赖。

**在线演示：<https://body-ledger.com>**（腾讯云轻量·中国香港，HTTPS 由 Let's Encrypt 签发并自动续期）

## 打开方式

最方便的方式：用浏览器直接打开项目中的 `index.html`，核心页面不需要安装任何依赖。浏览器对本地文件的存储行为可能不同，保存与备份仍建议用下面的本地服务方式。

推荐方式（Node.js 18 或以上）：

```powershell
npm start
```

浏览器访问 `http://127.0.0.1:4173`。按 `Ctrl+C` 停止本地服务。无需 `npm install`。

也可以在本目录运行 `python -m http.server 4173 --bind 127.0.0.1`。两种服务不要同时占用同一个端口。

## 试用路线

1. 首页默认展示**明确标记的吸烟示例**，没有预填用户年龄，也没有生成个人身体检测。
2. 填写 18 岁及以上的整数年龄，选择行为、数量/频率和持续时间，点击“查看身体影响”。
3. 移动到人体器官查看摘要，点击器官或下方文字按钮进入连续推进的特写。吸烟示例中的肺部可分步查看机制说明，支持暂停、重播和返回。可切换系统、正背面、全身/躯干。
4. 肺部吸烟结果中查看“近 12 倍”的**长期人群研究参考**。它指肺癌死亡相对风险，并附原始研究人群与限制，不能换算成抽一个月的个人风险。
5. 进入“证据与来源”阅读资料范围及原文；“可以怎么做”可加入今日计划。
6. 切换综合模式并选择抽烟和快走，查看心脏：不利影响和有益作用独立保留。
7. 从顶部进入今日计划，或在“数据与设置”导出备份、预览恢复及撤销恢复。

“进入沉浸视图”会收起输入区、放大人体。`Esc` 优先退出器官特写，再次按下退出沉浸视图。景深、视差和动效可关闭；系统的减少动态效果设置也会生效，特写与阶段按钮仍可使用。

## 已有范围

- 七类、30 项行为，12 个公开资料来源；本地受控名称/别名匹配。
- 模糊的“熬夜/晚睡”先区分睡眠不足或作息不规律；否定词不按子串误匹配。
- 吸烟、二手烟、活动不足的三个群体研究指标；其余影响以有来源的解释呈现。
- 情境更改后保留上一次结果并提示更新；不对研究数据做线性剂量推算。
- 十个器官/结构入口、机制路径示意、行动清单、同浏览器保存和手动文件备份。

## 资料与素材边界

健康结论由开发阶段核对 WHO、NCI、NHS 的公开原文整理，**尚未经临床专家审校**。用户年龄、性别用于说明适用范围；当前资料不提供精确的年龄/性别分层风险模型。

人体是对既有 SVG 的细化，肺、肠道叠加 OpenStax《Anatomy and Physiology》第一版许可素材的改编纹理；详情中附原图与署名。**当前写实程度尚未达到用户提供的医学插画参考图**，也未完成专业解剖审校。参考图未被直接复制到项目。

OpenStax 第一版内容的书籍许可元数据为 CC BY 4.0。原图、裁剪纹理的修改与来源记录在素材许可文件中；不以原作者名义背书本项目。没有使用收费生图工具。

## 保存与离线

- 记录保存在同一浏览器、同一站点的 localStorage；不是自动写入电脑上的 JSON 文件。
- JSON 备份包含明文生活记录，由用户主动导出；导入仅在本机读取。
- 恢复先校验并展示摘要，用户确认后整体替换；替换前保留一个恢复点，可撤销。
- 备份不会覆盖程序、资料库或素材。未知行为不参与分析，原关联已下架的任务仍保留。
- 所有运行所需文件随项目提供；不从外部 CDN 加载字体或人体图。打开原文链接时需要网络。
- 已加载页面的核心操作可断网使用；没有实现在线站点的离线缓存，不承诺断网后能重新打开公共网址。
