# 身知 BodyLens

把日常行为的后果映射到人体，帮助用户理解影响、查看证据并决定今天的一个小行动。

这是一个可运行的 Web 应用：没有账号、付费接口、数据库，也没有前端构建依赖。在线大模型只在「解读的措辞」上做可选增强，没接上时自动退回本地规则，功能不缺。

**在线演示：<https://body-ledger.com>**（腾讯云轻量·中国香港，HTTPS 由 Let's Encrypt 签发并自动续期）

## 10 分钟极速复现

从零到页面能跑，全部步骤不超过 10 分钟，**不需要安装任何 npm 包**。

### 环境要求

| 项 | 要求 | 检查命令 |
| --- | --- | --- |
| Node.js | **18 或以上**（推荐 20 LTS） | `node -v` |
| npm | 随 Node 附带即可，仅用于触发脚本 | `npm -v` |
| 浏览器 | 任意现代浏览器（Chrome / Edge / Firefox / Safari） | — |
| 网络 | **仅首次获取代码需要**，之后可断网运行 | — |

没装 Node 也能跑：项目是纯静态站点，用任何静态服务器托管本目录即可，例如 `python -m http.server 4173 --bind 127.0.0.1`。

### 依赖清单

**运行时依赖：零。** 仓库内没有 `node_modules`，也**不需要执行 `npm install`**。

`package.json` 里只有两个脚本，都指向仓库自带的文件，不引用任何第三方包：

| 脚本 | 实际执行 | 作用 |
| --- | --- | --- |
| `npm start` | `node scripts/serve.cjs` | 本机静态服务，绑定 `127.0.0.1:4173` |
| `npm test` | `node --test` | 运行 `tests/` 下的 85 项用例 |

`scripts/prepare-*.py` 是素材处理工具，**不是启动依赖**，只在重新生成纹理或人体图时才用到（需要 Pillow / NumPy）。

### 环境变量

AI 解读是**可选增强**，不配置也能完整使用（自动退回本地解读）。模板已随仓库提供：`server/.env.example`。

```bash
cd server
cp .env.example .env     # 然后填自己的值
```

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| `AI_API_KEY` | 否 | 大模型密钥。留空则 `/api/interpret` 返回 503，前端自动退回本地解读 |
| `AI_BASE_URL` | 否 | OpenAI 兼容接口地址，默认 `https://api.deepseek.com` |
| `AI_MODEL` | 否 | 模型名，默认 `deepseek-chat` |
| `PORT` | 否 | 监听端口，默认 `8080` |
| `BIND` | 否 | 绑定地址，Nginx 反代时保持 `127.0.0.1` |

`server/.env` 已在 `.gitignore` 中，永不提交。仓库里只有模板，没有任何真实密钥。

### 分步流程

| 用时 | 操作 | 应该看到 |
| --- | --- | --- |
| 0 分钟 | `node -v` | `v18` 及以上；低于 18 请先升级 |
| 1 分钟 | `git clone <仓库地址> && cd <仓库目录>` | 能看到 `index.html`、`app.js` |
| 2 分钟 | `npm start` | 终端输出 `BodyLens: http://127.0.0.1:4173`，**保持这个窗口不要关** |
| 3 分钟 | 浏览器打开 `http://127.0.0.1:4173` | 首屏写着「还没开始」，下面一行小字「先选一件今天发生的事，再点一下数量，第一笔就记上了」，右栏是一具人体 |
| 5 分钟 | 点「记一笔」里任一行为，再点一个数量按钮（例如香烟「+1 支」） | 大数字变成 `20 分钟`，紧跟一行灰色小字「资料折算的估算值 · 不是你的个人预测」，再往下是「大约等于 一集短剧」「涉及 肺部 · 心脏 · 大脑 · 口腔」 |
| 7 分钟 | 继续往下滚 | 依次是「这一天的解读」「如果一直这样」「近七天」。**空账本时这三块都在，但都不给数字**：推演卡写「这张卡还没有数字」，趋势写「还没有数据」，只给选一项的按钮 |
| 8 分钟 | （可选）按上面的环境变量配好 key，重启 `npm start` | 解读卡右上角标签从「本地解读」变成「AI 解读」 |
| 9 分钟 | 断网后**不要刷新**，直接再记一笔 | 功能不受影响，数字照常变化，标签仍是「本地解读」 |
| 10 分钟 | 点右栏任一器官 | 出现该器官详情：功能、关联行为、证据与来源 |

任何一步和「应该看到」对不上，问题一定出在前一步，按顺序往回查即可。

> **第 9 步为什么要写「不要刷新」**：这是一个纯静态站点，没有 service worker，页面本身不在本地缓存里。断网后刷新等于重新下载 `index.html`，打不开是必然的。断网可用的范围是「已经打开的页面继续记账、看器官、改计划、导出备份」，这些都在本机完成。不引入 service worker 是刻意的：它会把「改了代码但页面还是旧的」变成新的坑，而零依赖是这个项目的硬约束。
>
> 上面这张表在 2026-10-29 用一个脚本对**本地和线上**各实跑了一遍，12 项断言全部通过（脚本：`docs/tooling/preflight.cjs`）。2026-10-25 那次是在空目录里手动按顺序走一遍。改版后若这里对不上，以表格为准去修产品，不要改表格去迁就产品。

## 试用路线

1. 打开首屏。左上角是「今天从你这里拿走的时间」，右侧是一具可点的人体。没有记录时写着「还没开始」，不会编造数字。
2. 在「记一笔」里点一个行为，再点数量（例如香烟 5 支、屏幕时间 2 小时、睡眠不足）。**点数量即入账**，没有「提交」按钮。
3. 数字同时改变三处：总时间、它换算成什么事、落在哪些器官上。例如点香烟「1 支」会得到 `20 分钟` ≈「一集短剧」，涉及「肺部 · 心脏 · 大脑 · 口腔」。
4. 点右栏的器官，下方出现详情：这个器官做什么、今天这些行为跟它是什么关系、依据哪份研究、哪些地方还没有数据。
5. 滚到「如果一直这样」：用同一份权重换一个时间尺度（1 周 / 1 个月 / 1 年），看三者的差别。**这里的数字不是 AI 算的**，而是把权重表逐日累加得到的；AI 只负责换一种说法。
6. 进「行为资料库」看全部 30 项行为、七类分类（饮食饮水 / 睡眠作息 / 运动 / 久坐 / 用眼 / 烟酒 / 日常清洁）。每张卡片右下角有「记一笔 ＋」，点完会跳回今天页并选中该项。
7. 进「今日计划」写下今天想做的一件小事。勾选只表示这件事做了，**不代表器官已经变好**。
8. 右上角齿轮进「数据与设置」：导出备份、选择备份恢复、撤销恢复，以及景深与动效开关。

系统的「减少动态效果」设置会自动生效；关掉之后所有交互仍然完整可用。

## 已有范围

- 七类、30 项行为，12 个公开资料来源；本地受控名称/别名匹配，不调用大模型猜行为。
- 模糊的「熬夜 / 晚睡」先区分是睡眠不足还是作息不规律；否定词不按子串误匹配（「不抽烟」不会被识别成抽烟）。

- 今天页可点的器官 **7 个**：大脑、眼睛、口腔、肺部、心脏、肝脏、肠道。正面看不到的肾与脊柱在背面视图里；没有行为关联的器官不画，也不列进切换列表。
- 账本、推演、解读、计划、备份全部在本机完成；同一浏览器同一站点保存，可导出 JSON 备份、选择恢复并撤销。

## 资料与素材边界

健康结论由开发阶段核对 WHO、NCI、NHS 的公开原文整理，**尚未经临床专家审校**。用户年龄、性别用于说明适用范围；当前资料不提供精确的年龄/性别分层风险模型。

人体是对既有 SVG 的细化，肺、肠道叠加 OpenStax《Anatomy and Physiology》第一版许可素材的改编纹理；详情中附原图与署名。**当前写实程度尚未达到用户提供的医学插画参考图**，也未完成专业解剖审校。参考图未被直接复制到项目。

OpenStax 第一版内容的书籍许可元数据为 CC BY 4.0。原图、裁剪纹理的修改与来源记录在素材许可文件中；不以原作者名义背书本项目。没有使用收费生图工具。

## 保存与离线

- 记录保存在同一浏览器、同一站点的 localStorage；不是自动写入电脑上的 JSON 文件。
- JSON 备份包含明文生活记录，由用户主动导出；导入仅在本机读取。
- 恢复先校验并展示摘要，用户确认后整体替换；替换前保留一个恢复点，可撤销。
- 备份不会覆盖程序、资料库或素材。未知行为不参与分析，原关联已下架的任务仍保留。
- 所有运行所需文件随项目提供；不从外部 CDN 加载字体或人体图。打开原文链接时需要网络。
- 已加载页面的核心操作可断网使用；没有实现在线站点的离线缓存，不承诺断网后能重新打开公共网址。
